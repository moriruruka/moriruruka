## 关于

我做的事基本围着一条线转：**把一段看不懂的信号，变成能解释、能复现、能交给别人用的结果。**

代码大多长这样——一半在频谱里找结构（调制方式、码元宽度、阵列响应），一半在把这些过程包成别人能直接跑起来的东西。喜欢能跑起来的 demo，不喜欢只停在论文里的指标。

目前在写 [aninest-mcp](https://github.com/moriruruka/aninest-mcp)：把插画检索、长期记忆、人像识别这些日常需求，做成一个本地优先的 MCP 服务。

## 方向

| 方向 | 在做什么 |
| :--- | :--- |
| 🛰️ **雷达与阵列** | 相控阵、机载雷达的 MATLAB 仿真实验：方向图、波束形成、杂波与检测 |
| 📡 **信号识别与解调** | 调制类型识别与未知调制拒识、码元宽度盲估计、端到端解调网络 |
| 🧠 **深度学习** | 多尺度 ResNet、Transformer，在低信噪比下把结构从噪声里捞出来 |
| 🛠️ **工具与自动化** | 把重复的活儿包成 MCP 服务：插画检索、长期记忆、人像识别、网页阅读 |
